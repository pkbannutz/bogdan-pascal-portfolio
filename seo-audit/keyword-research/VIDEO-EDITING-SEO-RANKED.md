# Editing and video post-production: ranked UK professional naming and SEO

**Status:** DONE, research decision **NOT APPLIED**. **Research date:** 18 November 2026. **Scope:** https://bogdanpascal.com/filmmaker/services/editing/. **UK English Google Search.** 61 candidate queries, 50 numeric UK Google Ads estimates and 11 unknown; four Google Trends time windows; seven partial Google SERP tests; direct current GitHub HTML inspection and independently verified live raw HTML.

## Critical discovery: live page deliberately excludes itself from search

**P0, VERIFIED LIVE:** This existing linked production URL returns HTTP 200 but its actual HTML contains `<meta name="robots" content="noindex, nofollow">` (fresh Firecrawl `rawHtml`, 18 Nov 2026). Current GitHub `filmmaker/services/editing/index.html` matches. It also lacks an HTML canonical tag. Search engines instructed to exclude the page cannot be expected to rank it from this keyword plan. This must be resolved **before** polishing title and keyword copy if the owner intends it as a search landing page. **Only remove robots noindex with approval, preserving it on true staging previews.** The FPV and Colour Grading service pages have the same LIVE problem. Full separate verification: [LIVE-INDEXING-BLOCKERS-2026-11-18.md](LIVE-INDEXING-BLOCKERS-2026-11-18.md). [Google's robots meta documentation](https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag).

## 3. Trends: four time horizons, not monthly search counts

**Source:** [Six Google Trends UK web panels](editing-trends-raw-2026-11-18.json), saved 18 Nov 2026. Same-panel broad terms `video editor`, `film editor`, `video editing services`, `commercial video editor`, `video post production`. Panel values 0–100 **normalized to the selected terms and date interval**. Do not directly compare separate panels or conflate with Google Ads monthly volume.

- **All-time 2004 to Nov 2026:** average relative indices approx **48 / 5 / 0 / 0 / 0**. Generic editor language strongly dominates, but likely app/tool intent. This says nothing about hiring rates.
- **Last 5 years:** about **55 / 5 / 0 / 0 / 0**. Sustained generic topic popularity; tiny professional phrase suppression makes relative Trends weak for editor-hire decisions.
- **Last 12 months:** about **67 / 12 / 1 / 0 / 0**. Broad editor is prevalent, but the volume panel with commercial-specific terms is much smaller.
- **Last 3 months:** about **38 / 1 / 0 / 0 / 0**. Recent series is noisy, and final day can be partial.
- **Niche comparison:** `freelance video editor` / `social media video editing` register in specialist panels, while many phrases remain sample-sparse. Five-year relative averages about 4/3; 12-month about 16/13 in corresponding same-panel positions. These values are separately normalized and not an actual 4× increase.
- **Seasonality:** Not enough data to establish stable UK **commercial editor booking** seasons. Keyword searches and production schedules differ. Avoid trend-chasing for titles.
