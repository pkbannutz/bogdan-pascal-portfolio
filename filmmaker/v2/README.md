- Open `https://bogdanpascal.com/filmmaker/v2/review/` to compare Original vs V2.
- Open `https://bogdanpascal.com/filmmaker/v2/` to navigate the complete preview.
- V2 routes use noindex directives and are not linked from the original site. They are **not password protected**.
